# ChemCreate Help / 使用帮助

This is a short guide to the current ChemCreate app. Interface labels may follow your selected language. For private help, contact [quickiee@foxmail.com](mailto:quickiee@foxmail.com).

## English

### Start and save a document

Create a document from the app's document browser or **File → New** on Mac. Drawings are saved as editable `.chemcreate` documents. On Mac, use **File → Save** (`⌘S`); on iPhone and iPad, use the system document browser to manage files. You can reopen a saved document from Finder or Files. Keep `.chemcreate` for work you plan to edit again.

### Draw and edit

1. Choose **Bond** (`B` on Mac), then drag on the canvas to draw a bond or extend an atom. Clicking an existing bond with the Single Bond tool cycles its order.
2. Choose **Atom** to place or change an element. Choose **Ring** to place a ring; click an atom to attach it or a bond to fuse it. Tool disclosure menus offer variants.
3. Choose **Select** (`V` on Mac) to select and drag atoms or fragments. Open **Inspector** for precise atom and bond properties. Use **Undo/Redo** to reverse or restore edits.
4. With the Mac canvas focused, you can type an element such as `N`, `O`, `Cl`, or `Br` for the selected atom or newly drawn endpoint; `1`, `2`, and `3` set a selected bond's order.

On Mac, scroll to pan and pinch or Option-scroll to zoom. On iPhone and iPad, use one finger or Apple Pencil to edit and two fingers to pan or zoom. **Fit Structure** brings the drawing into view.

### Import, export, and analyze

- To bring in chemistry data, use **Chemical Formats → Import MOL, SDF or SMILES…** on Mac, or **More (⋯) → Import MOL, SDF or SMILES…** on iPhone/iPad.
- To share chemistry data, use the corresponding **Export MOL/SDF/SMILES** command or **More (⋯) → Export…**. These formats may not preserve all ChemCreate annotations or layout. Read any compatibility warning before confirming an export.
- For local NMR estimates, create or select a molecule and choose **NMR Prediction** from the tool palette or the Mac **Structure** menu. Predictions are computational estimates, not experimental measurements.

For problems with a document or format, see [Support](SUPPORT.md). Do not send confidential or unpublished structures through a public GitHub issue.

## 简体中文

### 新建与保存文稿

在应用的文稿浏览器中新建文稿；Mac 上也可以使用**文件 → 新建**。绘图以可继续编辑的 `.chemcreate` 文稿保存。Mac 上使用**文件 → 保存**（`⌘S`）；iPhone 和 iPad 上通过系统文稿浏览器管理文件。已保存的文稿可从 Finder 或“文件”App 重新打开。后续还要编辑时，建议保留 `.chemcreate` 文件。

### 绘图与编辑

1. 选择**键**工具（Mac 快捷键 `B`），在画布上拖动以绘制化学键，或从现有原子继续绘制。使用单键工具点击已有化学键，可循环切换键级。
2. 使用**原子**工具放置或更换元素；使用**环**工具放置环。点击原子可连接环，点击化学键可稠合环。工具旁的展开菜单可选择变体。
3. 使用**选择**工具（Mac 快捷键 `V`）选中并拖动原子或片段；在**检查器**中精确调整原子和化学键属性。使用**撤销/重做**恢复编辑。
4. Mac 画布取得焦点时，可以键入 `N`、`O`、`Cl` 或 `Br`，修改选中原子或刚画出的端点；`1`、`2`、`3` 可设置选中化学键的键级。

Mac 上滚动可平移画布，捏合或按住 Option 滚动可缩放；iPhone/iPad 上使用单指或 Apple Pencil 编辑，双指平移或缩放。**适合窗口**可将整幅绘图放入视野。

### 导入、导出与分析

- 导入化学数据：Mac 使用**化学文件格式 → 导入 MOL、SDF 或 SMILES…**；iPhone/iPad 使用**更多（⋯）→ 导入 MOL、SDF 或 SMILES…**。
- 导出化学数据：使用相应的**导出 MOL/SDF/SMILES**命令，或在 iPhone/iPad 的**更多（⋯）→ 导出…**中选择格式。外部格式可能无法保留全部标注或布局；确认导出前请阅读兼容性提示。
- 本地 NMR 估算：先创建或选择分子，再从工具栏中的 **NMR 预测**入口或 Mac 的**结构**菜单打开。预测值是计算估算，不等同于实验测量结果。

遇到文稿或格式问题，请查看[支持与联系](SUPPORT.zh-CN.md)。不要在公开 GitHub Issue 中提交机密或未发表的结构。
