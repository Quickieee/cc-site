Native. Local-first. Built for chemistry.

Chemistry drawing, built for Apple platforms.

ChemCreate is a native 2D chemical structure editor for Mac, iPhone, and iPad. Draw and edit molecular structures, keep complete editable documents, and exchange common chemistry formats without requiring an account or a cloud service.

ChemCreate

A focused molecular drawing workspace.

ChemCreate centers the workflows used repeatedly in chemistry: precise direct manipulation, durable document editing, chemical interchange, and native Apple document behavior.

Draw and edit

Atoms, common bonds, rings, stereochemical drawing, reactions, annotations, selection, movement, and undo/redo.

Native documents

.chemcreate preserves editable scene structure, molecular objects, reactions, text, style, and document metadata.

Chemistry interchange

Open and export common chemistry data through MOL, SDF, and SMILES workflows with explicit lossiness handling.

Apple-native workflow

Document-based interaction, Quick Look previews, native file access, English and Simplified Chinese interfaces.

Privacy by architecture

Your structures stay under your control.

The current ChemCreate app does not collect user data, run advertising or analytics SDKs, or send molecular structures and documents to the developer. Core editing and chemistry processing run on-device.
