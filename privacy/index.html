Privacy Policy

Effective: September 30, 2026 · Last updated: September 30, 2026

This Privacy Policy describes how the ChemCreate application for macOS, iOS, and iPadOS, and this public website, handle information.

1. App data collection

ChemCreate does not collect personal data from the app. The current app does not require a user account, include advertising or analytics SDKs, perform cross-app tracking, or operate a developer-controlled cloud service.

2. Chemical structures and documents

Chemical structures, .chemcreate documents, MOL/SDF files, SMILES content, annotations, and other user-authored document content are processed locally on the user's device. ChemCreate does not upload molecular structures or user documents to the developer.

Users choose where documents are stored or exported. If a user selects iCloud Drive or another third-party File Provider, that storage provider may process the file under its own terms and privacy policy. ChemCreate does not control those providers.

3. Local preferences

ChemCreate may store app preferences locally using Apple platform settings mechanisms, including preferences such as interface language and text size. These preferences are used to provide the requested app behavior and are not transmitted to the developer.

4. Network communication

The current ChemCreate app does not use a developer-operated network service and does not transmit app documents to the developer. Apple platform services, the App Store, iCloud, or a storage provider selected by the user may communicate independently of ChemCreate according to their own policies.

5. Analytics, advertising, and tracking

  • No advertising SDK is included.
  • No third-party analytics SDK is included.
  • ChemCreate does not track users across apps or websites.
  • ChemCreate does not sell user data.

6. Third-party open-source software

ChemCreate includes open-source components such as RDKit and related libraries for local chemistry processing. These embedded components do not independently provide user documents to the ChemCreate developer. See the Open Source Notices for the components and licenses included in the current release.

7. Data retention and deletion

ChemCreate does not maintain a server-side account database for app users, so the developer does not retain app account data or uploaded molecular documents. Users control their own files through Finder, Files, iCloud Drive, or another File Provider they choose and can delete those files through the corresponding system interface.

Local app preferences remain on the device according to Apple platform behavior until the user changes them, removes applicable app data, or uninstalls the app.

8. The ChemCreate website

This website is a static site hosted through GitHub Pages. The site itself does not intentionally use analytics, advertising, tracking pixels, third-party fonts, or application cookies. GitHub may process ordinary technical request information, such as IP address and request metadata, as part of providing GitHub Pages. That processing is governed by GitHub's own privacy terms.

GitHub General Privacy Statement

9. Changes to this policy

If ChemCreate later adds features that change its data practices, such as a developer-operated online service, account system, telemetry, or cloud-based processing, this policy and the corresponding App Store privacy disclosures will be updated before or with the relevant release.

10. Contact

For privacy or product questions, use the current contact route on the ChemCreate Support page. Do not post confidential, proprietary, or unpublished chemical structures in a public support issue.
