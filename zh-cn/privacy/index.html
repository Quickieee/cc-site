隐私政策

生效日期：2026 年 9 月 30 日 · 最后更新：2026 年 9 月 30 日

本隐私政策说明 ChemCreate 的 macOS、iOS、iPadOS 应用以及本官方网站如何处理信息。

1. App 数据收集

ChemCreate App 当前不收集个人数据。当前版本不要求用户账号，不包含广告或第三方分析 SDK，不进行跨 App 跟踪，也不运行由 ChemCreate 开发者控制的云服务。

2. 化学结构与文稿

化学结构、.chemcreate 文稿、MOL/SDF 文件、SMILES 内容、标注以及其他用户创建的文稿内容在用户设备本地处理。ChemCreate 不会将分子结构或用户文稿上传给开发者。

用户自行选择文稿保存或导出位置。如果选择 iCloud Drive 或其他第三方 File Provider，相应服务提供商可能根据其自身条款和隐私政策处理文件；ChemCreate 无法控制这些第三方服务。

3. 本地偏好设置

ChemCreate 可能使用 Apple 平台的本地设置机制保存界面语言、文字大小等偏好。这些设置仅用于提供用户选择的 App 行为，不会发送给开发者。

4. 网络通信

当前 ChemCreate App 不使用开发者运营的网络服务，也不会向开发者传输 App 文稿。App Store、iCloud、Apple 平台服务或用户自行选择的存储服务可能独立进行网络通信，并受其各自政策约束。

5. 分析、广告与跟踪

  • 不包含广告 SDK；
  • 不包含第三方分析 SDK；
  • 不跨 App 或网站跟踪用户；
  • 不出售用户数据。

6. 第三方开源软件

ChemCreate 包含 RDKit 等开源组件，用于设备本地的化学处理。这些嵌入组件不会独立向 ChemCreate 开发者提供用户文稿。当前版本包含的组件和许可证见开源许可声明。

7. 数据保留与删除

ChemCreate 不维护 App 用户的服务器端账号数据库，因此开发者不会保留 App 账号数据或上传的分子文稿。用户通过 Finder、文件 App、iCloud Drive 或自行选择的 File Provider 控制自己的文件，并可使用相应系统界面删除文件。

本地 App 偏好会依据 Apple 平台行为保留，直到用户修改设置、移除相关 App 数据或卸载 App。

8. ChemCreate 网站

本网站是托管在 GitHub Pages 上的静态网站。网站本身不主动使用分析服务、广告、跟踪像素、第三方字体或应用级 Cookie。GitHub 为提供 GitHub Pages 服务，可能处理 IP 地址、请求元数据等普通技术信息，该处理受 GitHub 自身隐私条款约束。

GitHub General Privacy Statement

9. 隐私政策变更

如果未来 ChemCreate 新增开发者运营的在线服务、账号系统、遥测或云端计算等改变数据实践的功能，本政策以及 App Store 对应的隐私披露将在相关版本发布前或同步更新。

10. 联系

隐私或产品问题请使用ChemCreate 支持页面列出的当前联系渠道。请勿在公开支持 Issue 中发布机密、专有、未发表或专利敏感的化学结构。
