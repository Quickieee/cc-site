ChemCreate

支持

当前 ChemCreate 版本的支持信息。

请保护机密化学信息。GitHub Issue 是公开的。请勿上传机密、专有、未发表、专利敏感、个人或安全敏感的化学结构和文稿。

联系与问题反馈

当前公开技术支持通过 ChemCreate 网站仓库的 GitHub Issue 提供。它适用于可复现 Bug、一般问题和无需共享机密数据的功能建议。

在 GitHub 提交支持请求

提交前请准备

  • ChemCreate 版本与 build 号；
  • macOS、iOS 或 iPadOS 版本；
  • 设备型号；
  • 清晰的复现步骤；
  • 预期行为和实际行为。

如果必须提供示例结构，请使用你有权公开、且不含机密信息的最小复现示例。

支持的平台

  • Mac：macOS 14 或更高版本，Apple 芯片；
  • iPhone：iOS 17 或更高版本；
  • iPad：iPadOS 17 或更高版本。

文稿与化学格式

ChemCreate 使用 .chemcreate 作为完整可编辑文稿格式，并支持 MOL、SDF 和 SMILES 交换。当外部格式不能表达全部 ChemCreate 场景内容时，App 的设计目标是显式提示兼容性或信息损失，而不是静默丢弃不支持的场景信息。

隐私

当前 App 不会将分子结构或文稿上传给开发者。详情见隐私政策。
