Support

Support information for the current ChemCreate release.

Protect confidential chemistry. The GitHub issue tracker is public. Do not upload confidential, proprietary, unpublished, patent-sensitive, personal, or security-sensitive structures or documents.

Contact and issue reporting

Public technical support is currently handled through the ChemCreate website repository's GitHub issue tracker. Use it for reproducible bugs, general questions, and feature requests that do not require sharing confidential data.

Open a support request on GitHub

Before reporting a problem

Please include:

  • ChemCreate version and build number;
  • macOS, iOS, or iPadOS version;
  • device model;
  • clear steps to reproduce the issue;
  • expected behavior and actual behavior.

If a sample structure is necessary, use a simple, non-confidential reproduction that you are permitted to share.

Supported platforms

  • Mac: macOS 14 or later on Apple silicon;
  • iPhone: iOS 17 or later;
  • iPad: iPadOS 17 or later.

Documents and chemistry formats

ChemCreate uses .chemcreate as its complete editable document format and supports MOL, SDF, and SMILES interoperability. When a foreign format cannot represent all ChemCreate scene content, the app is designed to surface compatibility or lossiness instead of silently discarding unsupported scene information.

Privacy

The current app does not upload molecular structures or documents to the developer. See the Privacy Policy for details.

Open-source software

Third-party notices for components used by ChemCreate are available on the Open Source Notices page.
